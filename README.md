# repo_aed

Mis apuntes y código del curso CS2023 (Algoritmos y Estructuras de Datos, UTEC).

La parte que uso de verdad está en `cs2023-lib/`: snippets de C++17 listos para
copiar en un contest, cada uno con su test. Todo compila con `make` desde esa
carpeta. Ver `cs2023-lib/README.md` para el detalle de qué archivo abrir.

```bash
cd cs2023-lib
make test
```
